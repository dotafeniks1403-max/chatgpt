# My Body – English

Offline Android body-parts game with 20 illustrated body parts, shuffled questions and answer positions, natural English narration at normal speed, positive feedback, facts, attempts, and a 20-star celebration. Speech uses en-GB-SoniaNeural at +0%. No network permission, ads, accounts or tracking.

Build: pip install edge-tts; python generate_audio.py; bash build.sh. Requires JDK 17 and Android SDK.
